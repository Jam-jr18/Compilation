System Integration and Architechture 2 (SIA)
This subject consists of the following activities/projects:

Activity 2 - guitar-system
The guitar system activity allows users to view music lists, check or learn guitar chords, and watch tutorial videos on YouTube. This activity helps users improve their guitar-playing skills, practice songs easily, and learn through step-by-step video tutorials.
Access: https://127.0.0.1:8000/items

Activity 3 - guitar-records
The guitar records activity is a CRUD-based system that allows users to manage a collection of guitars. Users can add, view, update, and delete guitar records, including details such as guitar brand name, model, and price. This activity helps organize guitar information efficiently and makes managing guitar collections easier.
Access: https://127.0.0.1:8000/records

Activity 4 - book-system 
The book system activity is a request form system for borrowing books from the library. It allows users to submit book borrowing requests by providing the necessary information about the borrower and the selected book. This activity helps organize library transactions, manage borrowing requests efficiently, and make the book lending process more convenient for users.
Access: https://127.0.0.1:8000/borrow-book

Activity 5 - weather-app
The weather app activity is connected to a weather API that provides real-time weather updates and information. It allows users to view current weather conditions, temperature, and other weather details for a specific location. This activity helps users stay informed about weather changes through accurate and updated data from the API.
Access: localhost:8000/dashboard
